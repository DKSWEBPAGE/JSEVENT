Check out the live interactive website:

## ✨ Features

- **Interactive UI:** Dynamic particle effects triggered by user interactions and mouse/touch events.
- **Pure JavaScript Events:** Demonstrates DOM event manipulation without heavy external dependencies.
- **CI/CD Integration:** Configured for automated deployment via GitHub Pages workflows.
- **Responsive Design:** Fits smoothly across modern browser displays and devices.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Hosting & Deployment:** GitHub Pages / CI/CD Pipelines
